# شروع کار با کارنما

کارنما دفتر ثبت کار فارسی و آفلاین برای Windows است. تسک‌ها، جلسه‌های کاری، پیوست‌ها، تنظیمات و نسخه‌های پشتیبان در حساب Windows شما ذخیره می‌شوند. نسخهٔ ۰٫۱٫۰ فقط برای Windows x64 ساخته شده است.

## نصب

۱. از [صفحهٔ انتشار KARNAMA](https://github.com/HadiSharifani/karnama/releases/latest) فایل `Karnama-0.1.0-win-x64.exe` را دریافت کنید.
۲. SHA-256 فایل را با `SHA256SUMS.txt` پیوست انتشار مقایسه کنید. در PowerShell:

```powershell
Get-FileHash .\Karnama-0.1.0-win-x64.exe -Algorithm SHA256
```

۳. نصب‌کننده را اجرا کنید. نصب برای حساب فعلی Windows انجام می‌شود و دسترسی Administrator لازم ندارد.
۴. نصب‌کننده امضای دیجیتال ندارد؛ Windows ممکن است هشدار ناشر ناشناس یا SmartScreen نشان دهد. منبع دریافت و checksum را بررسی کنید و برای نصب، تنظیمات امنیتی Windows را خاموش نکنید.

## اجرای نخست

در تنظیمات آغازین، نام نمایشی و عنوان شغلی گزارش شرکت را وارد کنید، ساعت تعهد روزانه، روزهای کاری و تعطیلی هفتگی را انتخاب کنید و سپس تقویم، پوسته و منطقهٔ زمانی را تنظیم کنید. مرز پیش‌فرض Work Date ساعت 06:00 در منطقهٔ زمانی انتخاب‌شده است. همهٔ این موارد بعداً از تنظیمات قابل تغییرند.

در نوار کناری، داشبورد، تسک‌ها، زمان‌سنج، تقویم کاری، تحلیل عملکرد، گزارش‌ها و تنظیمات را می‌بینید. برای شروع یک تسک بسازید و از زمان‌سنج مدت کار را ثبت کنید؛ یا جلسهٔ انجام‌شده را دستی وارد کنید. ثبت زمان برای «فعالیت عمومی» بدون تسک هم ممکن است.

## تهیهٔ نسخهٔ پشتیبان

به تنظیمات ← «پشتیبان‌گیری و بازیابی» بروید و «ساخت نسخهٔ دستی» را بزنید. فایل ZIP را روی رسانه‌ای خارج از این دستگاه یا حساب Windows کپی کنید. برنامه هنگام بازبودن تقریباً هر ۲۴ ساعت نسخهٔ خودکار می‌سازد و فایل‌های قدیمی را خودکار حذف نمی‌کند.

## محدودیت‌های مهم

- Windows 32-bit، ARM64، macOS و Linux در نسخهٔ ۰٫۱٫۰ پشتیبانی نمی‌شوند.
- نصب‌کننده امضای کد ندارد و به‌روزرسان خودکار موجود نیست.
- ثبت و مرور داده‌ها آفلاین کار می‌کند؛ بازکردن لینک تسک از مرورگر پیش‌فرض استفاده می‌کند و ممکن است به اینترنت نیاز داشته باشد.
