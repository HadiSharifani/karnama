# پرسش‌های پرتکرار

### آیا برای استفاده به اینترنت نیاز دارم؟

خیر. ثبت تسک، زمان، تقویم، تحلیل و پشتیبان‌گیری محلی انجام می‌شود. بازکردن لینک خارجی با مرورگر Windows ممکن است اینترنت بخواهد.

### آیا Windows 32-bit پشتیبانی می‌شود؟

خیر. v0.1.0 فقط installer ویندوز x64 دارد. Windows 32-bit در این نسخه پشتیبانی نمی‌شود.

### اگر برنامه هنگام تایمر بسته شد، زمان خاموشی ثبت می‌شود؟

خیر. پس از راه‌اندازی مجدد، بازهٔ احتمالی برای بررسی نمایش داده می‌شود؛ فقط پس از تأیید شما ثبت خواهد شد.

### Work Date چه فرقی با تاریخ تقویمی دارد؟

تاریخ تقویمی زمان واقعی فعالیت را نشان می‌دهد؛ Work Date روزی است که زمان برای گزارش و تعهد به آن نسبت داده می‌شود. جزئیات در [راهنمای تقویم و زمان](CALENDAR_AND_TIME_FA.md) آمده است.

### آیا بایگانی تسک جلسه‌های قبلی را پاک می‌کند؟

خیر. تسک و تاریخچه حفظ می‌شوند؛ زمان تسک بایگانی‌شده از گزارش‌های فعال کنار می‌رود و با بازیابی تسک دوباره قابل گزارش می‌شود.

### Backup رمزگذاری شده است؟

خیر. ZIP شامل checksum است، اما کارنما آن را رمزگذاری نمی‌کند. فایل را در محل محافظت‌شده نگه دارید یا پیش از انتقال رمزگذاری کنید.

### آیا uninstall داده‌ها را پاک می‌کند؟

خیر، uninstall دادهٔ کاربر و نسخه‌های پشتیبان را نگه می‌دارد. اگر قصد پاک‌کردن دستی دارید، ابتدا backup مستقل بگیرید و مسیر درست را شناسایی کنید.

### چرا Windows هشدار ناشر ناشناس می‌دهد؟

Installer امضای کد ندارد. فایل را فقط از صفحهٔ انتشار بگیرید و SHA-256 آن را با manifest رسمی مقایسه کنید.
